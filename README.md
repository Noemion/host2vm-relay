# Host2VMRelay

让 Windows 宿主机把**指定域名和 IP 的 TCP 请求交给虚拟机转发**，其他流量继续使用原有规则。支持密码或私钥登录、加密保存凭据、托盘后台运行和断线重连。

## 安装与准备

从 [Releases](https://github.com/Noemion/host2vm-relay/releases/latest) 下载安装包或对应架构便携包。安装包包含 .NET 桌面运行时，无需另装 .NET、Python 或编译器。已安装旧版时先卸载旧程序再安装，保留用户配置。

Windows 端安装 [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev)。虚拟机启用 SSH 和 TCP 转发，能够访问需要的网络；Windows 能通过虚拟机 IP 访问其 SSH 服务。

## 快速使用

1. 在“连接”页填写虚拟机 IP、SSH 端口和用户名，选择密码或私钥登录，然后连接。首次连接时核对服务器指纹。
2. 在“域名 / IP”页每行填写一个转发目标并保存。例如 `code.example.com`、`*.example.com`、`10.20.30.40` 或 `10.20.30.0/24`；不填写协议、端口或网页路径。
3. 在“接入 Clash”页生成脚本。没有自定义逻辑时选择**直接生成并复制**；已有扩展脚本时选择**导入 / 合并已有脚本**，粘贴或导入 `.js`/`.txt`，再点击**生成完整脚本并复制**。窗口支持预览、再次复制和另存为 `.js`。
4. 到 Clash 当前订阅 → 编辑扩展脚本，整体替换、保存并重新应用。选择规则模式，开启 TUN 与自动路由；DNS 劫持包含 `any:53`、`tcp://any:53`，路由排除添加虚拟机 IP 的 `/32`（IPv6 用 `/128`），不要排除转发目标 IP。

例如虚拟机 IP 为 `192.168.229.10`，排除项为 `192.168.229.10/32`。在 Clash 连接列表确认目标请求经过 `Host2VMRelay`。

## 现有脚本的合并

合并器保留原 JavaScript 的函数、变量和逻辑，先执行原脚本，再加入转发节点、规则、DNS 与 TUN 设置。支持常见的 `function main(config, profileName)` 或 `const main = (...) => ...`。原脚本必须同步处理配置对象；异步返回和无效返回值会由生成脚本明确报错，而不是静默丢弃用户配置。

这是 **JavaScript 扩展脚本**合并，不是 YAML 订阅文件合并。程序不运行用户代码；JavaScript 语法与实际效果由 Clash 校验。原脚本只在当前应用会话保留，另存为操作由用户选择路径。重新导入未手工改动的完整脚本可更新配置，不会层层套娃。修改过生成文件中原始脚本的内容时，请重新提供原脚本。

## 日常使用

关闭窗口缩至托盘；退出应用停止隧道。连接成功后启用本地文件规则，主动断开或正常退出后写入停用规则。规则文件不依赖本机 HTTP 服务，因此不再轮询 17861。异常终止或断电时可能残留上次活动规则，重新启动并正常断开可清除；已有连接和 DNS 缓存可能需要刷新。

配置位于当前用户的 **文档/Host2VMRelay**（支持 Windows 文档重定向）。安装和卸载不删除配置。旧版 LocalAppData 配置仅在默认文档目录尚无配置时迁移。

界面支持 DPI 自动缩放与可滚动内容，采用 12pt 字体；图标由 SVG 源文件生成 16/20/24/32/40/48/64/128/256 多种尺寸，并用于窗口、托盘、程序和安装包。

## 本地开发

```powershell
.\build.ps1 -Sync -Run
.\build.ps1 -Test
.\build.ps1 -Package -Install
```

所有构建和检查产物位于 `artifacts/`。完整说明见 [开发指南](docs/DEVELOPMENT.md)、[部署说明](docs/DEPLOYMENT.md) 和 [验证记录](docs/VALIDATION.md)。
