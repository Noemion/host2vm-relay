# Host2VMRelay

让 Windows 宿主机把**指定域名和 IP 的 TCP／单播 UDP 请求交给虚拟机转发**，未命中的流量保持原有分流。支持 SSH 密码／私钥、主机指纹校验、当前用户加密凭据、托盘、自动重连、按协议回退宿主机，以及旧版完整 Clash 脚本的增量更新。

## 安装与准备

安装包按 x64、x86 和 ARM64 分别提供。安装版需要对应架构的 [.NET 8 桌面运行时](https://dotnet.microsoft.com/download/dotnet/8.0)，安装器会在卸载旧版前检查依赖。便携包仍包含运行时，无需另装 .NET。Windows 客户端均不需要 Python、Node.js 或编译器。正式版本见 [Releases](https://github.com/Noemion/host2vm-relay/releases/latest)。

Windows 使用 Clash Verge Rev／Mihomo TUN。虚拟机支持 Linux x86_64 和 aarch64，需要 SSH 服务、允许命令执行和 TCP 转发，并能够访问目标网络。客户端使用 Rust 异步 SSH 内核。UDP 辅助程序随软件提供，连接时自动识别架构、上传、校验并启动；无需安装 Python、Rust 或 .NET，不安装系统服务、不使用 root、不额外开放虚拟机监听端口。

## 快速使用

1. 在“连接”页填写虚拟机 IP、SSH 端口和用户名，选择密码／私钥，核对首次连接的主机指纹。需要 UDP 时保持“透明转发 UDP”开启。
2. 在“转发规则”页每行填写目标并保存：`code.example.com`、`*.example.com`、`10.20.30.40`、`10.20.30.0/24`。`#` 为注释；不要填写协议、服务端口或 URL 路径。
3. 在“Clash 接入”中直接生成，或粘贴上个版本的完整脚本／原始 JavaScript。程序自动合并已有内容。生成并复制后，整体替换当前订阅的扩展脚本，保存并应用。
4. 在 Clash 设置中选择规则模式，开启 TUN 与自动路由；DNS 劫持保存 `any:53`、`tcp://any:53`；路由排除填写实际虚拟机 IPv4 的 `/32` 或 IPv6 的 `/128`，**不要排除需要转发的目标**。

普通客户端仍访问原域名、IP 和端口，不需要单独设置 SOCKS 或改成 localhost。UDP 域名需当前 Clash DNS 能解析（如企业 DNS）；仅在虚拟机 hosts 文件中存在的名称不能自动通过 Mihomo SOCKS UDP 解析。此点与 TCP 的远端解析存在差异，详见 [UDP 说明](docs/UDP_SUPPORT.md)。浏览器自定义安全 DNS 可能绕过期望的分流；规则还应包括登录跳转域名。

## 定时连接

在“设置 → 定时连接”启用并保存开始、结束时间，选择工作日或休息日（两项都选表示每天）。工作日包含中国法定调休上班日；休息日包括周末和法定假日，但排除调休上班日。默认关闭，旧配置保持手动连接方式。

按 Windows 本机日期和时间运行，开始时自动连接，结束时断开并恢复宿主机原有分流，通常在下一次 3 秒检查内执行。结束时间早于开始时间表示跨午夜，按开始当天的日期类型判断，例如工作日 22:00～02:00 会延续到次日凌晨；开始与结束不能相同。

程序需保持运行（可缩到托盘），不会唤醒休眠电脑。启动或恢复运行后会重新判断当前时段；连接失败沿用“断线后自动重连”设置，仅在时段内重试。手动断开会暂停本次时段，下个时段恢复；再次手动连接或重新保存定时设置可提前恢复。启用后时段外不允许连接；关闭定时后当前连接保持原状。

启用前请先手动连接一次并核对 SSH 指纹。定时保存会同时保存连接页信息；重启后的无人值守连接需要加密保存凭据，或使用无需口令的可用私钥。自动连接不会弹出首次信任对话框；未信任的主机需手动确认。

内置日历覆盖 **2026 年**，依据[国务院办公厅关于2026年部分节假日安排的通知](https://www.beijing.gov.cn/zhengce/zhengcefagui/202511/t20251104_4258873.html)。点击“设置 → 节假日日历更新 → 立即更新日历”可下载前一年、当年及已公布的次年安排，无需升级软件。在线数据来自根据国务院公告整理的 [holiday-cn](https://github.com/NateScarlet/holiday-cn)，优先 GitHub，网络失败时使用 jsDelivr 备用源。它是第三方整理的数据，不是官方 API。

也可启用“每月自动更新日历”，设置每月几号及当天开始时间。从该时间起每小时尝试一次，成功后当月停止；失败则仅当天继续重试。短月没有所选日期时按月末执行（例如每月 31 日在二月按 28／29 日执行）。当天较晚启动会执行当前小时的尝试；错过整天则等下个月，也可随时手动更新。无需登录或配置密钥，不会唤醒电脑。

界面显示最近尝试、最近成功、更新结果、可用年份及本月状态。更新记录和日历缓存保存在 `settings.json`，随配置迁移；断网或更新失败保留原缓存。尚未公布的次年不算有效日历，也不阻止已有年份更新成功。缺少对应年份安排时，工作日／休息日定时暂停并提示更新日历；“每天”模式不受影响。

## 不可用时自动回退

虚拟机优先但不是唯一出口。TCP 与 UDP 独立检测；UDP 组件失败时 UDP 回退，正常的 TCP 继续经过虚拟机。虚拟机失联时两者恢复宿主机**原有 Clash 规则**，不是把全部流量改为 DIRECT，也不是关闭整个 TUN。现有 Mieru 的 UDP 设置继续保留。

启用自动重连时通道恢复后重新使用虚拟机；手动断开不会触发重连。目标规则在断开和重连时保持不变，由健康 fallback 组切换流向，避免 Clash 服务保留暂停规则副本后无法恢复。应用每 200 毫秒主动同步 TCP、UDP 健康状态，目标是在通道状态改变后 1 秒内切换新请求；这不是 SSH 登录、网络恢复或已有会话迁移的时限。应用退出后的回退由脚本原有健康探测接管。已有 TCP/UDP 会话可能需要客户端重试，本来仅虚拟机可达的服务不能保证宿主机回退后仍可达。

“转发规则”和“Clash 接入”页均提供“Clash 规则应用情况”，检查已保存规则、文件和内核条数、分流入口及策略组选择。数量一致不代表内容一致；需要确认具体目标时使用“检测路由是否生效”。规则刷新接口成功也不代表最新内容已加载，先检查具体差异，再决定是否重新应用配置。

UDP 支持单播请求与回包，不支持广播、组播和 SOCKS 分片。数据报在 SSH/TCP 中封装，延迟特性不同于原生 UDP；不承诺所有 QUIC、实时音视频或多媒体协议都已经实测。

## 增量合成与 TUN 设置

生成格式分为用户区和托管区，程序不执行用户 JavaScript。再次导入完整脚本时提取并保留用户区，只更新托管实现；已知的 v0.4.0～v0.5.0 格式可迁移，新格式允许直接编辑用户区。未知托管修改、损坏标记、截断和无法归属的尾部代码会报告冲突，不静默丢弃。原始脚本必须提供同步 `main(config, profileName)`；语法和运行结果由 Clash 校验。这不是 YAML 订阅合并器。

TUN 开关、协议栈、设备名、自动路由、路由排除、自动选择网卡、DNS 劫持、严格路由、MTU 等界面字段沿用 Clash 传入值，不由生成器强制覆盖。若其他全局扩展也改写受管字段，应分别移除冲突。升级新程序后仍需重新生成脚本，已粘贴的旧文本不会自动更新。

VMware NAT 流量由宿主机的 `vmnat.exe` 发起。生成的 TCP、UDP 规则会排除该进程，以及来源为所填虚拟机地址的请求，让这些流量继续匹配 Clash 原有规则，避免将虚拟机自己的 VPN 接入流量再次送回虚拟机。宿主机访问同一域名仍可使用虚拟机转发，无需删除整条域名规则。

这项保护需要 Clash 识别进程。如果配置关闭了进程识别，生成器会将 `find-process-mode` 从 `off` 改为 `strict`，按规则需要查询进程。它不保证覆盖其他虚拟化软件或无法识别来源的转发方式；原有 Clash 规则也必须能够访问 VPN 接入地址。仅更新程序而未重新应用脚本时，旧规则仍会生效。

## 配置与界面

默认配置目录是 Windows 实际“文档/Host2VMRelay”（支持重定向）。在**设置 → 配置存储 → 更改目录**中迁移已保存配置；已有目标需确认后先备份再替换，原目录保留。路径定位文件是 `%LOCALAPPDATA%\Host2VMRelay\storage.json`，只保存路径，不保存凭据。自定义目录不可用时明确报错，不偷偷切换到空白配置。卸载不删除配置；跨 Windows 用户迁移后需重新输入凭据。

界面采用卡片布局，默认正文和编辑字体为 9 pt。左侧导航固定显示，左下角“关于”提供项目链接和版本更新。窗口有最小尺寸限制，Windows DPI 感知保持 PerMonitorV2，显示设置可调整内容缩放和字体大小。Alt+1～Alt+6 切换页面，Ctrl+Tab 循环；脚本工作区 Ctrl+Enter 生成并复制。

## 开发与验收

```powershell
.\build.ps1 -Sync -Run
.\build.ps1 -Test
.\build.ps1 -Package -Install
```

构建与检查产物统一位于 `artifacts/`。Actions 包含 Windows 编译、脚本／配置／图标／五档 DPI、本机 UDP 套接字检查，以及 Linux 独立网络中的真实 Mihomo TUN＋SSH 回退验收，两侧检查通过后才发布新版本。模拟 DPI 不等于物理高 DPI／跨显示器验收，Linux TUN 检查也不替代真实 Windows 公司网络测试。
