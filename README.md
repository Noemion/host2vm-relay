# Host2VMRelay

让 Windows 宿主机把**指定域名和 IP 的 TCP 请求交给虚拟机转发**，其他流量继续使用原有规则。支持密码或私钥登录、加密保存凭据、托盘后台运行和断线重连。

## 安装与准备

从 [Releases](https://github.com/Noemion/host2vm-relay/releases/latest) 下载安装包或对应架构便携包。安装包包含 .NET 桌面运行时，无需另装 .NET、Python 或编译器。升级前从托盘退出旧程序；安装器先卸载当前用户的旧版本再安装，保留用户配置。

Windows 端安装 [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev)。虚拟机启用 SSH 和 TCP 转发，能够访问需要的网络；Windows 能通过虚拟机 IP 访问其 SSH 服务。

## 快速使用

1. 在“连接”页填写虚拟机 IP、SSH 端口和用户名，选择密码或私钥登录，然后连接。首次连接时核对服务器指纹。
2. 在“转发规则”页每行填写一个转发目标并保存。例如 `code.example.com`、`*.example.com`、`10.20.30.40` 或 `10.20.30.0/24`；不填写协议、端口或网页路径。编辑器上方显示保存操作，下方提示规则数量与未保存状态。
3. 在“Clash 接入”页生成脚本。没有自定义逻辑时选择**生成并复制**；已有扩展脚本时选择**合并已有脚本**，粘贴或导入 `.js`/`.txt`，再点击**生成并复制**。脚本工作区支持双栏预览、再次复制和另存为 `.js`。
4. 到 Clash 当前订阅 → 编辑扩展脚本，整体替换、保存并重新应用。选择规则模式，并在 **Clash 设置 → TUN** 中开启 TUN 与自动路由；DNS 劫持分别添加 `any:53`、`tcp://any:53`，路由排除添加虚拟机 IP 的 `/32`（IPv6 用 `/128`），不要排除转发目标 IP。

例如虚拟机 IP 为 `192.168.229.10`，排除项为 `192.168.229.10/32`。可通过“复制路由排除”取得当前地址；详细 TUN 提示在“查看设置说明”中展开。在 Clash 连接列表确认目标请求经过 `Host2VMRelay`。

## 桌面工作区

四个页面采用侧边导航、轻边框卡片和统一的圆角输入区。状态显示在页头，主次按钮、焦点和禁用状态分别呈现。窗口较窄时导航自动转为顶部栏，保留完整页面入口；脚本双栏自动改为上下排列，生成、复制和保存操作独立于编辑器滚动区域。

正文和编辑器基准字号为 12pt，按 Windows DPI 缩放，不通过缩小文字塞入内容。保留系统标题栏、原生输入、密码遮罩和文件对话框。快捷键：`Alt+1`～`Alt+4` 切换页面，`Ctrl+Tab` 循环切换，脚本窗口中 `Ctrl+Enter` 生成并复制。

“运行日志”支持复制、导出和清空。清空只作用于本次运行日志，不删除连接设置；分享前请检查日志中的主机地址、用户名等信息。界面设计规范见 [UI_DESIGN.md](docs/UI_DESIGN.md)。

## 现有脚本的合并

合并器保留原 JavaScript 的函数、变量和逻辑，先执行原脚本，再加入转发节点、规则和 Fake-IP DNS 配置。支持常见的 `function main(config, profileName)` 或 `const main = (...) => ...`。原脚本必须同步处理配置对象；异步返回和无效返回值会由生成脚本明确报错。

这是 **JavaScript 扩展脚本**合并，不是 YAML 订阅文件合并。程序不运行用户代码；JavaScript 语法与实际效果由 Clash 校验。原脚本只在当前应用会话保留，另存为操作由用户选择路径。重新导入未手工改动的完整脚本可更新配置，不会层层嵌套。修改过生成文件中的原始脚本时，请重新提供原脚本。

输入或合并选项改变后，旧预览失效，复制和保存按钮禁用，必须重新生成。Windows 编辑器换行处理与原脚本完整性都有回归检查。

## TUN 设置被接管的提示

TUN 开关、协议栈、设备名、自动路由、路由排除、自动选择网卡、DNS 劫持、严格路由和 MTU 应在 Clash 设置界面调整，不由本扩展脚本强制覆盖。生成器会保存进入脚本时这些字段的值，合并后恢复；未提供的字段不会被旧脚本再次注入。原脚本的其他 TUN 选项仍保留，自动重定向字段也按相同方式处理。

遇到“扩展配置或脚本写入了由应用设置接管的字段 tun.dns-hijack，这些值已被丢弃”时，请使用修复后的程序重新生成完整脚本，替换 Clash 中已保存的旧脚本；仅更新程序不会自动更新 Clash 的脚本。未修改过的旧版完整脚本可重新导入合并。

在 Clash 的 TUN 设置中保存 `any:53` 和 `tcp://any:53`，并把实际虚拟机地址加入路由排除。不要直接删除传入配置的整个 `tun` 对象或已有字段。其他全局扩展、订阅扩展若仍在改写受管字段，需要分别处理；本生成器不能撤销其他扩展阶段已经产生的提示。若提示为 `dns.*`，还需检查 Clash 的 DNS 覆写设置是否与脚本要求的 Fake-IP 配置一致。

## 日常使用与验证

关闭窗口缩至托盘；退出应用停止隧道。连接成功后启用本地文件规则，主动断开或正常退出后写入停用规则。规则文件不依赖本机 HTTP 服务，不再轮询 17861。异常终止或断电可能残留上次活动规则，重新启动并正常断开可清除；已有连接和 DNS 缓存可能需要刷新。

配置位于当前用户的 **文档/Host2VMRelay**，支持文档重定向。安装和卸载不删除配置。旧版 LocalAppData 配置仅在默认文档目录尚无配置时迁移。

自动化覆盖 100/125/150/175/200% DPI 消息回归、导航、输入与滚动可达性、脚本预览和反复缩放。云端消息注入不等于物理高 DPI 或跨显示器验收，原生检查严格核对实际系统 DPI，见 [DPI_VALIDATION.md](docs/DPI_VALIDATION.md)。
