# Host2VMRelay v0.6.10

本版完善安装器的语言选择逻辑，每次安装都跟随当前 Windows 显示语言。

## 更新内容

- 首次安装、重新安装和升级均重新检测当前用户的 Windows 显示语言，不再沿用上次安装选择的语言。
- 取消语言选择弹窗，直接进入对应语言的标准现代向导。
- 内置简体中文和英文；未匹配内置语言时使用英文。地区、日期和数字格式不影响安装语言。

## 升级说明

v0.6.8 及更新版本可在“关于”页面检查更新，点击“下载并升级”。升级会停止当前转发连接，退出应用并打开安装程序。

更早版本需要手动下载对应架构的安装包。安装版需要对应架构的 .NET 8 桌面运行时，现有配置会保留。本版无需重新生成 Clash 脚本。

本次语言调整仅涉及安装器，应用主界面仍使用中文。不同 Windows 显示语言下的实际安装交互由用户验收。
