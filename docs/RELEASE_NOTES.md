# Host2VMRelay v0.6.15

修复断开虚拟机后重新连接，Clash 仍使用暂停规则而无法恢复中转的问题，并新增规则应用情况检查。

## 更新内容

- 断开、重连和退出不再用暂停内容覆盖目标规则；由 TCP、UDP 独立健康状态控制回退与恢复，避免依赖 Clash 服务复制规则文件。
- 在“转发规则”和“Clash 接入”新增“Clash 规则应用情况”，核对已保存规则、文件与内核条数、分流入口、当前模式和策略选择。
- 明确区分未加载、规则数量不同、通道与策略不一致和检查未完成。条数一致仅证明数量一致，具体目标继续使用路由诊断确认。
- 应用每 200 毫秒通过本地控制接口更新两种协议的健康状态，SSH 与 UDP 探测并行执行，健康租约过期后停止中转。
- 复用协议定义与控制客户端；新增真实 Mihomo 反复切换、租约失效、控制接口失败和取消检查，纳入发布前网络验收。

## 时限与范围

目标为通道状态变化后 1 秒内切换新请求。本机真实 Mihomo 策略测试达到亚秒级；这不是硬实时保证，也不包含 SSH 重新登录、配置重载或已有 TCP/UDP 会话迁移。应用退出后由 Clash 脚本原有探测周期接管，控制接口不可用时应用会明确记录异常。

## 升级说明

安装后保留现有配置。使用当前 v0.6.x 完整脚本无需重新生成；升级后先检查规则应用情况，若内核还持有旧版暂停规则副本，重新应用一次 Clash 配置并复查。之后正常断开、重连不需要重复重启内核。
