# Host2VMRelay v0.4.2

## 本次改进

- 补齐 100%、125%、150%、175%、200% 独立 DPI 回归检查；200% 不再只检查能否生成截图，而是检查字号比例、文字容量、控件重叠、输入与按钮的滚动可达性、键盘焦点以及窗口工作区边界。
- 主窗口和脚本窗口都进行三轮 DPI 往返，检查字体能否恢复，避免重复缩放。
- 修复规则页高缩放下“保存规则”按钮不可通过滚动完整访问的问题，将凭据说明改为独立换行显示。
- 让显式设置字体的标题、规则、日志和脚本编辑框跟随窗体字体比例，保持字体族和样式，不叠加额外 DPI 倍率。
- 图标按请求尺寸精确输出，补齐 175% 所需的 28/56 像素尺寸；脚本窗口图标也随 DPI 更新。
- 新增原生 DPI 验收入口，实际系统 DPI 不匹配时返回 BLOCKED；不允许用模拟结果代替原生 200% 验收。

## 下载与升级

下载 `Host2VMRelay-0.4.2-Setup.exe`，或选择对应架构的便携 ZIP。运行时已经包含，无需自行编译。升级前从托盘退出旧程序；用户配置仍保留在 Windows 文档目录下的 Host2VMRelay 文件夹。

本版保留 v0.4.1 的 Clash 受管 TUN 字段修复。从 v0.4.0 或更早版本升级时，仍需重新生成完整扩展脚本并整体替换 Clash 中保存的旧脚本；TUN 参数在 Clash 设置界面配置。

## 验收范围

Actions 使用 Windows 云端桌面执行自动化检查，报告记录 `GetDpiForWindow` 和 WinForms `DeviceDpi`。100% 原生检查与 125/150/175/200% 的父窗口 DPI 消息注入回归分别记录。消息注入不是修改真实显示器缩放，也不完整复现原生子窗口 DPI 通知；不能据此宣称所有真实高 DPI 屏幕、Windows 11 笔记本或多显示器拖动场景都已通过实机验收。

结果与实际桌面截图位于 Actions 的 `Host2VMRelay-checks`，代码、命令和实机核查要求见 `docs/DPI_VALIDATION.md`。原生 200% 检查必须在实际 192 DPI 的显示器上执行。应用和安装包未进行代码签名。
