# Host2VMRelay v0.6.7

本版补充麒麟虚拟机的执行授权说明，方便处理辅助程序启动时的授权提示。

## 更新内容

- 连接页新增“麒麟执行授权”说明。用户可在虚拟机弹窗中允许当前程序运行。
- 新增“复制关闭命令”按钮。希望关闭后续执行授权提示的用户，可复制命令到虚拟机终端执行。复制成功后，界面直接显示反馈。
- 辅助程序启动被拒绝或超时时，错误提示提供授权处理方法。
- 部署文档补充执行控制的状态查询和恢复方法。

## 执行控制的影响范围

界面提供以下命令，由用户在麒麟虚拟机中手动执行：

```sh
sudo /usr/sbin/setstatus -f exectl off -p
```

该命令永久关闭系统级执行控制，影响所有程序，重启后仍生效。请确认符合设备管理要求。软件仅提供说明和复制按钮，不自动修改虚拟机安全策略。

## 升级说明

退出旧程序后，安装对应架构的新版本。安装版需要 .NET 8 桌面运行时，便携包包含运行时。

已使用 v0.6.6 脚本的用户无需重新生成脚本。从更早版本升级时，请重新生成并应用 Clash 扩展脚本，以启用 VMware NAT 流量排除规则。
