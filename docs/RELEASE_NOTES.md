# Host2VMRelay v0.6.14

本版新增开机自启动与静默启动设置。

## 更新内容

- 在“设置 → 启动方式”中分别启用开机自启动和静默启动，修改后立即保存，并在界面显示结果。
- 开机自启动在当前用户登录 Windows 后运行应用，无需管理员权限。Windows 的“启动应用”设置仍可单独禁用该启动项。
- 静默启动时仅显示托盘图标，不先弹出主窗口；双击托盘图标即可打开窗口。
- 升级时保留本程序的启动项，更改安装路径后更新启动路径；卸载时清理对应启动项。

## 使用说明

两个选项默认关闭、独立生效。需要登录后直接进入托盘时，请同时启用。静默启动不代表自动连接虚拟机。

## 升级说明

可在“关于”页面检查更新，或下载对应架构的安装包。现有配置会保留，无需重新生成 Clash 脚本。
