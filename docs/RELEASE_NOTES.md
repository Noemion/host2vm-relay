# Host2VMRelay v0.8.0

完善无需密钥的升级机制：GitHub API 限流、连接失败或超时时，自动改用公开发布页检查更新。

## 更新内容

- 优先使用公开 API；不可用时通过本仓库最新正式发布页的重定向确定版本，不解析易变的网页 HTML。
- 从对应版本的 SHA256SUMS.txt 获取校验值，按 Windows 系统架构选择 x64、x86 或 ARM64 安装包，并确认文件存在及大小。
- 两条路径复用同一套版本、来源、大小和 SHA-256 校验；错误或缺失的完整性信息不会通过回退绕过。
- API 单次检查限时 8 秒，整体检查限时 45 秒；用户取消后不会继续尝试回退。两个来源均不可用时提示检查网络，无需配置密钥。
- 增加限流、网络异常、超时、架构选择、异常重定向、重复校验记录和取消回归测试。

## 验证

本地回归通过。另使用实际公开发布页查询 v0.7.0 的 x64 安装包，完成下载和 SHA-256 校验；测试未运行安装程序。发布流水线继续执行三架构构建、界面、网络与安装包验收。

## 升级说明

已安装旧版且遇到 API 限流时，需要先从 GitHub 发布页手动下载一次本版本；旧版软件不会自动获得尚未安装的新回退逻辑。之后可继续使用“关于 → 检查更新 → 下载并升级”。不需要 GitHub 账号、访问令牌或 SSH 密钥。
