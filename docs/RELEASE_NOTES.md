# Host2VMRelay v0.6.4

本版加强并发连接保护，改进运行状态和日志交互。当前为待验收版本。

## 本版变更

- 为转发满载时的健康探测保留连接容量，减少错误回退。
- 修复新连接接入与关闭之间的竞争条件。
- 修复 UDP 并发注册可能越过上限的问题。
- 统一健康检查时间参数，覆盖 SSH 和 UDP 探测耗时。
- 拒绝上游 SOCKS 返回的错误协议头。
- 连接页显示当前转发数量及过载拒绝次数。
- 日志支持暂停显示。选中文字时暂停刷新，便于查看和复制。
- 限制每次日志刷新量，缓存未变化的规则编译结果。
- 并发上限默认 512，设置范围为 64～2048，下次连接生效。UDP 回复队列共享 16 MiB 内存预算。

## 并发与验证范围

TCP 连接和 UDP 关联共用转发名额。入口额外保留 64 个名额用于握手及健康探测。达到上限时拒绝新请求，避免无限排队。

新增测试在独立进程中校验 512 和 2048 条本机并发连接，覆盖双向数据、满载探测、过载拒绝及资源回收。此测试没有经过 SSH，不能作为完整链路的容量认证。现用 SSH.NET 动态转发仍有逐连接阻塞读取的问题，真实 SSH 高并发能力尚未验证。

安装包按 x64、x86 和 ARM64 提供。安装版需要对应架构的 .NET 8 桌面运行时；便携包包含运行时。升级前请从托盘退出旧程序。

长时间运行、多显示器切换、真实业务网络压力和安装交互仍需验收。程序及安装包尚未进行代码签名。
