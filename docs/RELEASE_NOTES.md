# Host2VMRelay v0.6.4

本版将 SSH 转发内核改为 Rust，移除虚拟机对 Python 的依赖，并改进并发保护和运行诊断。

## 本版变更

- 使用 Rust 异步 SSH 内核，减少大量连接等待网络时的线程占用。
- 自动部署 Linux x86_64 或 aarch64 静态 UDP 辅助程序，无需安装语言运行时。
- 保留首次主机指纹确认，内部转发端口使用随机凭据认证；断开时回收子进程及通道。

- 为转发满载时的健康探测保留连接容量，减少错误回退。
- 修复新连接接入与关闭之间的竞争条件。
- 修复 UDP 并发注册可能越过上限的问题。
- 统一健康检查时间参数，覆盖 SSH 和 UDP 探测耗时。
- 拒绝上游 SOCKS 返回的错误协议头。
- 连接页显示当前转发数量及过载拒绝次数。
- 日志支持暂停显示。选中文字时暂停刷新，便于查看和复制。
- 限制每次日志刷新量，缓存未变化的规则编译结果。
- 并发上限默认 512，设置范围为 64～2048，下次连接生效。UDP 回复队列共享 16 MiB 内存预算。

## 并发与验证范围

TCP 连接和 UDP 关联共用转发名额。入口额外保留 64 个名额用于握手及健康探测。达到上限时拒绝新请求，避免无限排队。

测试分别覆盖本机转发层和真实 SSH 链路。Rust 内核通过临时 OpenSSH 服务完成 512 和 2048 条同时连接的数据传输、TCP 半关闭、UDP 收发和退出清理。结果不代表用户虚拟机在长期负载、丢包或业务流量下的性能保证。

安装包按 x64、x86 和 ARM64 提供。安装版需要对应架构的 .NET 8 桌面运行时；便携包包含运行时。升级前请从托盘退出旧程序。

长时间运行、多显示器切换、真实业务网络压力和安装交互仍需验收。程序及安装包尚未进行代码签名。
