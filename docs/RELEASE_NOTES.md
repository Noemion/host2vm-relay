# Host2VMRelay v0.6.13

本版新增路由诊断，通过实际连接记录判断目标请求是否经过中继。

## 更新内容

- 在“Clash 接入”输入目标网址，点击“检测路由是否生效”。
- 显示本地规则匹配、规则文件一致性、Clash 当前模式与分流入口。
- 通过 Clash 发起 TCP 请求，核对对应连接的链路和命中规则。仅有刷新成功或规则条数相同，不会报告路由已生效。
- 独立显示 TLS 证书校验结果，支持取消和超时。检测结果同步写入运行日志。

## 检测范围

诊断使用 Clash Verge 现有的本地控制接口，需要启用 HTTP 或混合代理端口。它只验证本次代理请求，不代表浏览器 TUN、DNS、UDP 或网页登录全部正常。

检测仅使用目标域名和端口，不发送网址中的路径、查询参数、浏览器 Cookie 或登录凭据，也不会关闭证书校验。

## 升级说明

可在“关于”页面检查更新，或下载对应架构的安装包。现有配置会保留，无需重新生成 Clash 脚本。
