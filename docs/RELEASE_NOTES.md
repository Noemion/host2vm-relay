# Host2VMRelay v0.6.0

## 本次更新

- 新增透明单播 UDP 中继。客户端仍使用原 IP／端口；域名使用当前 Clash DNS 的解析结果。通过已验证的 SSH 会话启动内存中的 Python UDP 组件，不要求逐个服务映射端口，也不要求每个应用重新设置代理。
- TCP、UDP 独立健康检测。虚拟机不可用时回退宿主机原有 Clash 分流，而不是一律 DIRECT；UDP 单独失败不阻断仍正常的 TCP。启用自动重连时恢复虚拟机优先路径；主动断开后不自行连接。日志和托盘提供去重的 warning。
- 脚本内的健康 fallback 组使用 PASS 继续原有规则，即使程序异常退出、活动规则文件残留，也能在检测周期后回退。保留 Mieru UDP 设置及 Clash 界面接管的 TUN 字段。
- 新增“设置”页，自定义配置目录、打开目录、迁移已保存配置、备份并替换已有目标以及恢复默认目录。默认仍是 Windows 文档/Host2VMRelay；旧目录保留。
- 增量合成支持上一版完整脚本。保留用户区域，替换托管区域；允许用户区域长度变化，拒绝静默覆盖未知的托管区修改。导入、直接粘贴、预览、复制和另存为共用同一套校验。
- 正文和代码字号调整为 9.6pt，组件及默认窗口约为上版的 80%，卡片和表单留白进一步收紧。保留 PerMonitorV2 与 100/125/150/175/200% DPI 回归。
- 安装器采用兼容 DIB+PNG 的 ICO。构建检查 EXE 多尺寸资源提取和 Windows Shell 提取结果，不仅检查 `.iss` 是否声明了图标。
- 安装包文件名明确包含 `win-universal`，便携包分别标注 `win-x64`、`win-x86`、`win-arm64`。

## 安装与升级

下载 `Host2VMRelay-0.6.0-win-universal-Setup.exe` 或对应架构的便携 ZIP。Windows 运行时和依赖已包含，不需要安装 .NET SDK、Node.js 或 Python。升级前先从托盘退出旧程序，安装器先卸载旧版再安装，配置与配置目录定位文件保留。

**升级后必须更新 Clash 脚本。**在“Clash 接入 → 合并已有脚本”中粘贴或导入上个版本的完整脚本，生成后复制到当前订阅的扩展脚本并重新应用。仅安装新程序不会把旧脚本中的 TCP-only 节点和规则改成新实现。原脚本用户区保留；托管区被手动修改时会提示冲突，而不是丢弃改动。

远端需要允许 SSH 命令执行和 TCP 转发，且有 `python3`；此版针对 Linux／兼容 POSIX shell 环境。没有 Python 时 UDP 回退宿主机，TCP 仍可使用。程序不自动安装 Python、修改远端防火墙或增加系统服务。

## 明确的边界

UDP 域名须能由现有 Clash DNS 解析；仅在虚拟机 hosts 文件中存在的名字不等于已支持自动 UDP 远程解析。需要企业 DNS 的环境，应在 Clash 中保留或配置相应解析能力。详见 `docs/UDP_SUPPORT.md`。

UDP 经 SSH/TCP 封装，不支持广播/组播，不保证切换中的已建连接零中断。UDP 健康自检不代表所有目标服务都可用。

自动化验收分别包含 Windows 本机传输、Windows GUI/图标/配置/脚本检查，以及 Linux 实际 TUN/SSH 网络回退。高 DPI 消息注入不等于物理显示器 200% 或跨屏实测；真实 Windows TUN、公司内网服务、ARM64 硬件和显示器环境仍需对应设备验证。程序与安装包当前未做代码签名。
