# Host2VMRelay v0.9.0

新增定时连接：按开始、结束时间和中国工作日／休息日自动控制虚拟机中继。

## 更新内容

- 在“设置 → 定时连接”选择开始、结束时间；工作日包含法定调休上班日，休息日排除调休上班日，两项都选表示每天。
- 支持跨午夜时段，日期类型按开始当天判断。到点自动连接或断开，结束后恢复宿主机原有分流。
- 手动断开后本次时段不再自动拉起，下个时段恢复；自动重连也遵守时间范围。
- 启动、静默启动和恢复运行后均重新判断当前时段。连接过程中到达结束时间会取消连接尝试。
- 新增“立即更新日历”及每月自动更新日期、开始时间设置；当天每小时重试，成功后当月停止，短月按月末执行。
- 显示最近尝试、最近成功、更新结果和可用年份；日历与状态随配置保存，更新失败继续使用缓存。

## 使用说明

定时默认关闭，旧配置无需迁移。启用前请先手动连接并核对服务器指纹；需要无人值守重启连接时，请保存凭据或使用可用私钥。程序必须保持运行，可缩到托盘；按 Windows 本机时间运行，不会唤醒休眠电脑。

内置中国节假日安排覆盖 2026 年，依据[国务院通知](https://www.beijing.gov.cn/zhengce/zhengcefagui/202511/t20251104_4258873.html)。在线更新使用第三方 [holiday-cn](https://github.com/NateScarlet/holiday-cn) 整理的数据，下载前一年、当年和已公布的次年安排；优先 GitHub，失败时使用 jsDelivr。缺少对应年份安排时，按工作日／休息日的定时连接会暂停并提示更新日历；每天模式继续可用。

每月自动更新默认关闭，需程序保持运行；当天稍晚启动会尝试一次，错过整天则等下个月。下一年尚未公布不影响当年更新成功，不会保存为有效空日历。
