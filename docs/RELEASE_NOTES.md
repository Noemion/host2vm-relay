# Host2VMRelay v0.4.3

## 显示与验收修复

本版包含 v0.4.2 的全部 DPI 修复与验收项，并修正桌面截图复核中发现的脚本预览换行问题。导入、合并和预览统一采用 Windows 编辑框的 CRLF 换行，生成器仍按原来的规则解析原脚本；新增原生编辑框行数和原脚本完整性检查，覆盖 LF、CRLF、CR 三类输入。

- 独立检查 100%、125%、150%、175%、200%，检查字号比例、文字容量、控件重叠、输入与按钮的滚动可达性、键盘焦点和窗口工作区边界。
- 主窗口和脚本窗口进行三轮 DPI 往返，检查字体恢复，避免累计缩放。
- 修复规则页高缩放下“保存规则”按钮不可通过滚动完整访问的问题；凭据说明改为独立换行显示。
- 显式设置字体的标题、规则、日志和脚本编辑框跟随窗体字体比例，保留字体族和样式，不叠加额外 DPI 倍率。
- 图标按请求尺寸精确输出，包括 175% 的 28/56 像素尺寸；脚本窗口图标随 DPI 更新。
- 原生 DPI 验收入口严格核对实际系统 DPI，错误的显示环境返回 BLOCKED，不以模拟结果代替原生 200% 验收。

## 下载与升级

下载 `Host2VMRelay-0.4.3-Setup.exe`，或选择对应架构便携 ZIP。运行时已包含，无需自行编译。升级前从托盘退出旧程序；用户配置保留在 Windows 文档目录下的 Host2VMRelay 文件夹。

本版保留 v0.4.1 的 Clash 受管 TUN 字段修复。从 v0.4.0 或更早版本升级时，需要重新生成完整扩展脚本并整体替换 Clash 中保存的旧脚本；TUN 参数在 Clash 设置界面配置。

## 验收范围

Actions 使用 Windows 云端桌面执行检查并记录 `GetDpiForWindow` 和 WinForms `DeviceDpi`。100% 原生检查与其他比例的父窗口 DPI 消息注入回归分别记录。消息注入不是修改真实显示器缩放，也不完整复现原生子窗口 DPI 通知；不能据此宣称真实 Windows 11 笔记本的全部高 DPI 或多显示器拖动场景已经通过实机验收。

结果、指标与实际桌面截图位于 Actions 的 `Host2VMRelay-checks`，原生测试命令和操作要求见 `docs/DPI_VALIDATION.md`。原生 200% 检查必须在实际 192 DPI 的显示器上执行。应用和安装包未进行代码签名。
