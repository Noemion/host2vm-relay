# Host2VMRelay v0.6.11

本版支持在安装向导中关闭正在运行的应用，并继续安装。

## 更新内容

- 应用正在运行或缩到托盘时，安装向导正常打开，不再要求先手动退出。
- 确认安装后，在标准页面选择自动关闭应用，再继续旧版处理和新文件安装。关闭应用会断开当前转发连接，请先保存尚未保存的设置。
- 更改安装路径时，仍检测旧目录中的应用。关闭失败或选择不关闭时，停止旧版移除。
- 保留从准备到安装完成的总进度、操作记录和现有配置，并阻止同时运行多个安装器。

## 升级说明

v0.6.8 及更新版本可在“关于”页面检查更新，点击“下载并升级”；也可以下载对应架构的安装包直接运行。

安装版需要对应架构的 .NET 8 桌面运行时。本版无需重新生成 Clash 脚本。实际关闭与安装交互仍需用户验收，开发检查不执行安装程序。
