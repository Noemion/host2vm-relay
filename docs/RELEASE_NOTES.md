# Host2VMRelay v0.6.5

本版改进页面切换、托盘菜单和脚本工作区，并完善连接失败提示。

## 界面改进

- 页面切换增加约 120 毫秒的渐显过渡。连续切换时，直接响应最后一次选择。
- 过渡期间可以立即点击、滚动和输入。关闭 Windows 动画效果时，程序跳过渐显。
- 修复页面切换和滚动时的局部重绘问题，保留输入内容及滚动位置。
- 托盘菜单跟随 Windows 明暗主题。菜单宽度按文字调整，减少多余留白。
- 统一菜单间距、分隔线和悬停效果。连接和断开选项随实际状态更新。
- 移除脚本工作区的合并复选框，自动处理空白输入、代码片段和完整脚本。
- 统一脚本标签与编辑框样式，修复矮窗口下的边框裁切。

## 连接修复

- 右上角分别显示连接失败和 UDP（用户数据报协议）连接失败，并提供错误原因。
- SSH（安全外壳协议）会话关闭后，不再沿用此前的健康状态。
- 虚拟机辅助程序完成握手后，才确认 UDP 组件启动成功。
- 辅助程序执行受阻时，提示检查虚拟机安全授权，避免误报为普通超时。

## 升级说明

升级前，请从托盘退出旧程序。安装包按 x64、x86 和 ARM64 提供。

安装版需要对应架构的 .NET 8 桌面运行时。便携包包含运行时。

升级后，虚拟机可能再次请求辅助程序的执行授权。请核对文件后，在虚拟机中允许执行。程序不会自行关闭安全检查。

## 验证范围

自动检查覆盖脚本生成、页面布局、快速切换、键盘操作和连接状态。网络检查覆盖 TCP（传输控制协议）半关闭、UDP 收发、并发限制及资源清理。

本地已检查原生 200% 缩放和模拟缩放。多显示器切换及安装交互仍由用户验收。
