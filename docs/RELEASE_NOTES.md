# Host2VMRelay v0.6.12

本版完善安装向导，让安装选项和版本变化更清楚。

## 更新内容

- 首屏介绍应用用途和功能。内容放在标准欢迎页内，不使用滚动条。
- 后续依次显示安装路径、开始菜单名称、桌面快捷方式和安装确认页。
- 确认页显示已有版本、目标版本、运行时和应用运行状态。
- 根据版本判断首次安装、升级、重新安装或降级。安装按钮和进度说明同步显示操作类型。
- 降级时提示设置兼容性；旧版本无法识别时明确提示，避免误报首次安装。

## 升级说明

可在“关于”页面检查更新，或下载对应架构的安装包。应用正在运行时，安装向导支持自动关闭应用后继续安装。

安装版需要对应架构的 .NET 8 桌面运行时。现有配置会保留，无需重新生成 Clash 脚本。

开发检查不执行安装程序。中英文页面显示、版本识别和实际安装交互由用户验收。
