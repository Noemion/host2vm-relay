# Host2VMRelay v0.6.3

本版修复窗口显示和滚动异常，改进连接管理、脚本编辑及安装体验。

## 界面与操作

- 恢复系统原生滚动，修复滚动时的残影和控件错位。
- 修复高 DPI（屏幕像素密度）下的重复缩放问题。
- 支持 75%～110% 的界面缩放和 8～10.5 pt 的字体设置。默认字体为 9 pt，显示设置下次启动生效。
- 窗口和托盘图标显示连接状态，支持区分连接中、已连接和部分协议可用。
- 按钮操作后显示界面反馈，减少额外确认。

## 连接与脚本

- 断开连接时在后台释放 SSH 资源。重连等待旧连接清理完成。
- 健康检查独立运行，减少界面繁忙对连接状态的影响。
- 批量刷新转发日志，并限制待显示记录数量。连接结束时记录传输字节数及原因。
- 新增连接通知、转发请求日志和重连间隔设置。
- 脚本编辑整合到主窗口，支持切换原始脚本和生成结果。
- 支持完整脚本、自定义函数及函数体代码片段，生成时检查语法。
- Clash 接入页说明配置生效步骤。复制或刷新规则后，仍需确认 Clash 已应用配置。
- 修复健康检查中的连接复用问题。

## 安装与升级

- 分别提供 x64、x86 和 ARM64 安装包，每个架构对应一个 EXE 文件。
- 安装版需要对应架构的 .NET 8 桌面运行时（8.0.x）。便携 ZIP 包含运行时，可离线使用。
- 安装器在卸载旧版前检查运行时。缺少依赖时显示下载地址，并保留旧版。
- 用户确认安装后才处理旧版本。检查、卸载、安装和收尾共用总进度条。
- 进度条下方显示命令、文件处理和快捷方式等操作记录。
- 卸载失败时停止安装，并显示原因。

升级前，请从托盘退出旧程序。升级会保留用户配置和配置目录定位文件。

## 验证与已知限制

用户已确认本次滚动显示修复可用。程序自检和隔离桌面的启动、滚动检查已通过。GitHub 发布流程还会执行 Windows 检查和网络集成测试。

安装器两秒内显示界面仍是验收目标，尚未确认在所有环境下达标。安装的取消、失败及连续升级场景仍需按验收文档检查。

开发期间，两份临时测试安装器被 Microsoft Defender 隔离。原因尚未确认，相关测试程序不包含在发布附件中。程序和安装包尚未进行代码签名。
