# Host2VMRelay v0.6.2

本版整理了测试代码，应用功能与 v0.6.1 相同。

## 本版变更

- 移除旧的独立域名解析检查。现有端到端测试已覆盖对应场景。
- 移除测试流程中不再使用的配置文件输出。

## v0.6.1 已有修复

从 v0.6.0 升级的用户，也将获得以下修复。

- 修复 TCP（传输控制协议）连接异常后的资源回收问题。单向传输失败时，程序会结束另一方向的等待。正常半关闭时，程序仍允许反向响应传输完成。
- 修复 UDP（用户数据报协议）单向接收时的误断开问题。任一方向成功传输数据，都会刷新空闲计时。
- 改进 DNS（域名系统）查询。后台查询设置了并发上限、超时和缓存。慢查询不会阻塞其他会话或健康检查。会话关闭后，程序会丢弃迟到的解析结果。
- 修复配置保存失败后的状态不一致问题。规则和主机指纹在保存成功后生效。配置字段为空或端口无效时，程序会提示错误，并保留原文件。
- 统一 SSH（安全外壳协议）会话的资源管理。连接取消、健康检查和 UDP 恢复使用同一套流程。

## 安装与升级

安装版文件名为 `Host2VMRelay-0.6.2-win-universal-Setup.exe`。便携版提供 x64、x86 和 ARM64 三种架构的压缩包。

Windows 客户端已包含运行所需的依赖，无需另行安装 .NET、Python 或 Node.js。升级前，请从托盘退出旧程序。升级会保留现有配置和配置目录定位文件。

从 v0.6.0 或 v0.6.1 升级时，可继续使用已有 Clash 脚本。从 v0.5.0 或更早版本升级时，请完成以下操作。

1. 打开“Clash 接入”，选择“合并已有脚本”。
2. 导入旧的完整脚本，生成新脚本。
3. 将新脚本应用到 Clash，启用 UDP 节点和独立的健康回退组。

虚拟机需要允许 SSH 命令执行和 TCP 转发。使用 UDP 时，虚拟机还需要安装 `python3`。远端依赖、防火墙和系统服务由用户配置。

## 验证范围

本版通过了以下自动化检查。

- Windows 构建，以及配置、脚本和图标检查。
- 五档显示缩放比例检查，以及原生缩放检查。
- Windows 和 Linux 上的 TCP、UDP 连接管理测试。
- Linux 上使用真实 Mihomo 虚拟网卡的透明代理测试，以及 SSH 故障回退测试。
- x64 和 x86 发布程序的自检，以及安装器图标检查。

显示缩放检查包含 DPI（每英寸点数）消息注入。消息注入测试与物理显示器测试的验证范围不同。窗口隐藏或桌面无法交互时，检查结果为 BLOCKED（无法执行）。

以下场景仍需在对应环境中验证：公司网络中的 Windows 透明代理、ARM64 实机、长期高吞吐传输和物理多显示器切换。

## 使用限制

- UDP 数据通过 SSH 连接封装传输，底层使用 TCP。
- UDP 转发不支持广播、组播和 SOCKS 代理协议分片。
- UDP 目标域名仍需由现有 Clash 域名解析配置处理。
- 故障切换时，客户端可能需要重试已有连接。
- 程序和安装包尚未进行代码签名。
