# Host2VMRelay v0.6.1

## 本次修复

- 修复 TCP 单方向异常后另一方向永久等待的问题，异常连接及时回收；正常半关闭仍允许完整响应返回。
- 修复 UDP 持续单向接收仍在两分钟后断开的问题，成功的上下行数据均刷新空闲期限。
- DNS 查询使用有界后台解析、超时和缓存；单个慢域名不再阻塞其他 UDP 会话或健康探测，关闭会话后的解析结果不会重新建立连接。
- 配置候选值保存成功后才投入使用，保存失败不再让未保存规则或主机指纹生效；配置空字段、非法端口会明确报错并保留原文件。
- 提取独立的 SSH/UDP 会话管理，统一取消、健康检查、资源释放和 UDP 恢复；生产程序与网络验收使用同一实现。
- 精简重复测试逻辑，所有 JavaScript 回归执行 C# 生产生成器的输出。补充 TCP 异常、单向 UDP、慢 DNS、取消连接与保存失败等必要回归。

## 安装与升级

下载 `Host2VMRelay-0.6.1-win-universal-Setup.exe`，或对应 x64、x86、ARM64 的便携 ZIP。Windows 运行时和依赖已包含，无需安装 .NET、Python 或 Node.js。先从托盘退出旧程序再升级，现有配置与配置目录定位文件保留。

从 v0.6.0 升级可继续使用已有 Clash 脚本。若从 v0.5.0 或更早版本升级，需要在“Clash 接入 → 合并已有脚本”中导入旧完整脚本，生成并应用到 Clash，才能启用 UDP 节点与独立健康回退组。

虚拟机仍需允许 SSH 命令执行和 TCP 转发；UDP 需要 `python3`。本版不会自动安装远端依赖、修改防火墙或建立系统服务。

## 验证范围

发布由 Windows 构建、配置/脚本/图标/五档 DPI、原生 TCP/UDP 生命周期测试，以及 Linux 实际 Mihomo TUN/SSH 回退验收共同把关。安装器包含三种架构，x64/x86 发布程序执行自检。

DPI 消息注入不等同于物理高 DPI 或跨屏验收；隐藏窗口或不可交互环境会报告 BLOCKED，不能冒充通过。真实 Windows 公司网络 TUN、ARM64 实机、长期高吞吐与物理多屏仍需对应环境验证。

UDP 通过 SSH/TCP 封装，不支持广播/组播或 SOCKS 分片；UDP 域名仍需现有 Clash DNS 能够解析。故障切换中的已建连接可能需要客户端重试。程序和安装包当前未做代码签名。
