# Host2VMRelay v0.5.0

## 新版桌面界面

本版以克制的浅色工作区重新组织连接、转发规则、Clash 接入和运行日志。采用侧边导航、轻边框卡片、圆角输入容器和石墨色文字，主操作使用低饱和绿色；保留 Windows 原生标题栏、输入控件、密码遮罩和文件对话框。

- 窗口较窄时导航切换到顶部，四个页面入口完整保留，不通过缩小文字容纳内容。
- 连接信息和隧道偏好分组，私钥相关字段只在私钥模式下显示。
- 转发规则在编辑区上方保存，下方显示去重后的规则数与未保存状态；空白和注释不计入规则数。
- Clash 接入按生成脚本、配置虚拟网卡、验证连接三个步骤呈现，详细说明可展开，并支持复制当前虚拟机路由排除地址。
- 脚本工作区宽屏下左右对照，窄屏下上下排列；生成、复制、另存为和关闭操作独立于编辑器滚动区域。原脚本完整性、预览换行和旧结果失效机制保持不变。
- 日志提供复制、导出和清空；清空日志不会修改连接或规则设置。分享日志前请检查主机地址、用户名等内容。
- 统一输入框、按钮、卡片间距和焦点反馈，修复 125% 下原生无边框输入框的高度取整问题。
- 快捷键：Alt+1～Alt+4 切换页面，Ctrl+Tab / Ctrl+Shift+Tab 循环切换；脚本窗口 Ctrl+Enter 生成并复制。

SSH 连接、安全存储、服务器指纹校验、本地规则文件与 Clash 受管 TUN 字段处理没有更换实现。本版不包含完整深色模式和自定义标题栏。

## 下载与升级

下载 `Host2VMRelay-0.5.0-Setup.exe`，或选择对应的 `win-x64`、`win-x86`、`win-arm64` 便携 ZIP。Setup.exe 为三架构合一安装包，运行时与依赖已包含，无需自行编译或安装 .NET SDK、Node.js。

升级前从托盘退出旧程序。安装器检测到当前用户已安装旧版时先卸载再安装；用户配置保留在 Windows 文档目录下的 Host2VMRelay 文件夹。

从 v0.4.3 升级只涉及界面和交互，不要求重新配置已有可用的 Clash 脚本。从 v0.4.0 或更早版本升级仍需用新程序生成完整脚本、整体替换 Clash 旧脚本并重新应用；TUN 参数在 Clash 设置界面配置。

## 验证范围

工作流执行 Windows 编译、自检、JavaScript 回归、图标检查、100/125/150/175/200% DPI 消息注入检查、对应桌面截图、三架构打包，以及 x64/x86 发布程序自检。新增导航状态、认证字段展开、空规则与去重计数、日志清空不改设置、TUN 说明展开和脚本编辑区可用高度检查。

高比例 DPI 消息注入不等于把物理显示器设置为对应比例。原生测试记录 GetDpiForWindow 并严格核对目标 DPI，96 DPI 桌面不能冒充原生 200% 验收。真实高 DPI、多显示器切换、原生文件对话框和高对比度主题仍需相应设备的实机验证，见 docs/DPI_VALIDATION.md。

所有构建与验收产物仍在 artifacts/。程序和安装包当前未做代码签名。
