# Host2VMRelay v0.6.9

本版将安装界面调整为 Inno Setup 的标准现代向导，保留升级进度与操作记录。

## 更新内容

- 恢复标准窗口尺寸、字体、页眉、图片和导航按钮，移除覆盖原生页面的自定义面板和分区布局。
- 使用标准进度页面显示安装条件检查与旧版处理过程，在进度条下方显示具体操作记录。
- 准备阶段与安装阶段延续同一总进度和操作记录，成功完成后才显示 100%。
- 保留 .NET 8 桌面运行时检测、旧版本处理、配置保留和失败提示。

## 升级说明

v0.6.8 用户可在“关于”页面检查更新，点击“下载并升级”。升级会停止当前转发连接，退出应用并打开安装程序。

更早版本需要手动下载对应架构的安装包。安装版需要对应架构的 .NET 8 桌面运行时，现有配置会保留。本版无需重新生成 Clash 脚本。

安装界面的实际运行与升级交互由用户验收。
