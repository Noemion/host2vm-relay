# Host2VMRelay v0.6.8

本版新增“关于”页面，支持检查 GitHub 正式版本、下载安装包并启动升级。

## 更新内容

- 将左下角“仅转发选定流量”替换为“关于”按钮。关于页面在主窗口内打开，可返回原页面。
- 固定使用左侧导航，并设置窗口最小尺寸。移除窄窗口布局及自动切换逻辑，保留 Windows DPI 缩放和显示偏好设置。
- 显示当前版本，提供 GitHub 项目链接和发布说明入口。
- 支持手动检查最新正式版本。发现新版本后，可点击“下载并升级”。软件根据 Windows 系统架构选择安装包。
- 下载过程显示进度并支持取消。下载完成后校验文件大小和 SHA-256，校验通过才启动安装程序。
- 安装包保存在系统临时目录。取消或下载失败时清理文件，下次启动时清理已使用的安装包及超过 7 天的旧下载。

## 升级说明

升级会停止当前转发连接，退出应用并打开安装程序。若安装程序启动失败，应用会重新打开并显示原因。

安装版需要对应架构的 .NET 8 桌面运行时。便携版也通过安装程序升级，原便携目录保留。

v0.6.7 及更早版本需要先手动安装本版，之后可在“关于”页面检查更新。已使用 v0.6.6 或 v0.6.7 脚本的用户，无需重新生成 Clash 脚本。
