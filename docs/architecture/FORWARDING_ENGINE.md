# 转发内核

2026-09-28：采用 .NET 界面、Rust 异步 SSH 内核和两个 Linux 静态辅助程序。生产代码不再依赖 SSH.NET 或 Python。

## 组件边界

- `RelaySession`：连接生命周期、健康租约和 UDP 恢复。界面仍唯一拥有重新连接 SSH 的意图。
- `RelaySocksServer`：兼容现有 Clash 的本机 SOCKS5 入口、TCP/UDP 共用的准入上限、请求日志、健康 URL。默认 512，可配置 64～2048。
- `RelayCoreProcess`：持有一个 Rust 子进程，校验发行文件完整性，通过继承管道发送凭据、主机信任决定和控制请求。
- `native/relay-core`：Tokio 异步套接字、russh 加密及 SSH 通道复用、TCP 双向复制、远端组件部署。四个异步工作线程，不为每个连接分配系统线程；文件读取、密钥解密和标准输入可能使用额外阻塞线程。
- `native/vm-agent`：Linux x86_64/aarch64 的 musl 静态程序，将 SSH 通道中的数据报发送到虚拟机网络。无需语言运行时。

TCP：客户端 → .NET SOCKS → 认证的回环连接 → Rust SSH direct-tcpip → 虚拟机目标。
UDP：客户端 → .NET UDP ASSOCIATE → 有界数据报帧 → Rust SSH exec → 静态辅助程序 → 虚拟机 UDP 套接字。

UDP 仍承载在 SSH/TCP 上，链路丢包可能导致等待；更换语言没有消除这一协议限制。原有 Clash 分流、独立 TCP/UDP 健康状态和宿主回退保持不变。

## 控制与安全边界

控制协议为 UTF-8 JSON 行，版本 1，单条上限 64 KiB。握手事件为 hostKey 和 ready；请求通过 id 关联 probe、udp 的响应。凭据仅进入继承的标准输入，不写入参数、日志或临时配置。首次信任经界面确认，已有指纹必须匹配；SSH 重新协商不能接受不同的主机公钥。

内核仅监听 127.0.0.1 的临时端口，使用每进程随机生成的 256 位凭据进行 SOCKS 用户名/密码认证。普通程序使用的 .NET SOCKS 入口保持兼容；管理消息没有网络监听端口。发行包 SHA-256 清单用于发现缺失或损坏，不等同于数字签名，也不防御能同时替换程序和清单的攻击者。

辅助程序按架构选择，只将本地计算出的哈希插入固定远端命令。上传使用权限受限的临时文件，在远端校验 SHA-256 后原子替换。缓存路径为 `~/.cache/host2vm-relay/<hash>/agent`，无 root、无常驻服务、无额外监听端口。基础环境需提供 POSIX shell、uname、sha256sum、mktemp 及常见文件操作工具。策略禁止执行用户目录程序或目录为 noexec 时报告 UDP 不可用，继续保留 TCP，不绕过系统策略。

## 生命周期与资源边界

父进程管道 EOF、SSH 关闭或内核退出后，任务集合取消全部转发。界面断开时只终止自己持有的子进程，并等待退出后允许重连。辅助程序在输入 EOF 或 30 秒输入空闲后退出，缓存文件保留。TCP 使用独立半关闭语义，客户端发送 EOF 后仍允许服务器返回数据。

除 .NET 准入限制外，内核也限制连接数和控制请求数。TCP 每方向使用 32 KiB 复制缓冲；SSH 每通道窗口 256 KiB，消息队列有界。虚拟机 UDP 最多 2048 个目标套接字，每目标最多八个待发送包，合计 16 MiB 发送字节预算，输出队列最多 128 帧。Windows UDP 回复共用 16 MiB 字节预算。过载允许丢弃 UDP 包。

DNS 同时最多四个系统解析；两秒后调用方放弃结果，阻塞解析本身继续持有许可直到实际结束。不能取消的系统解析不会产生无限替代线程。数字 IP、已有会话和 UDP 探测不等待域名解析。目标套接字空闲 120 秒后回收。

## 验证范围

`tests/test-rust-engine.py` 通过临时账号和本机 OpenSSH 验证密码、普通/加密密钥、拒绝主机指纹、内部端口认证、512/2048 条真实 SSH 通道、TCP 半关闭、UDP 空包/最大数据报、辅助程序部署和父进程退出。报告包含 Rust 内核资源快照，不能理解为整个应用或虚拟机的资源总量。

`tests/test-native-agent.py` 对两个 Linux 静态程序执行协议测试，ARM64 在 CI 中使用 QEMU；这不等于真实 ARM64 虚拟机吞吐验收。Windows TransportHarness 复用生产会话代码，验证取消、回收与异步 SOCKS 接入。真实 Clash TUN 的整体回退测试沿用隔离网络命名空间流程。
