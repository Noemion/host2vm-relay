# 路由诊断

在“Clash 接入”的测试网址中填写目标地址，点击“检测路由是否生效”。检测使用已保存规则；编辑后请先保存。

| 检测结果 | 含义与处理 |
| --- | --- |
| 本地规则未命中 | 普通域名仅精确匹配。需要包含子域名时使用 `*.example.com`。域名解析后的 IP 规则是否匹配，以实际连接为准。 |
| 规则文件与保存内容不同 | 连接可能未就绪，健康检查暂时停用了转发。先检查连接状态。 |
| Clash 未加载分流入口 | 重新生成并应用当前订阅的扩展脚本。 |
| 实际链路包含 Host2VMRelay 节点 | 已确认这次 TCP 请求选择了中继节点。网页内容和登录状态仍需另行验证。 |
| 实际链路为 DIRECT 或其他节点 | 查看同次请求的实际命中规则，检查规则遗漏、模式和策略组回退。 |
| TLS 证书失败 | 若收到证书，说明已到达 TLS 阶段。检查证书信任、域名和有效期，不要关闭验证。 |
| 没有捕获连接记录 | 不能判断链路成功，即使代理端口接受了请求。 |

诊断按自己的本地源端口、目标域名、目标端口及 TCP 类型匹配连接，不借用同域名的其他连接作为证据。控制接口错误、代理认证要求、超时和取消均显示未完成的检测阶段。

当前使用 Clash Verge 的本地命名管道，不启用新的网络控制端口。实际请求需要 HTTP 或混合代理端口；仅启用 SOCKS 端口时会说明无法实测。规则集条数不能证明内容完全一致。

本次检查不验证浏览器 TUN/DNS 接管、UDP、页面内容或登录。只发送域名和端口，HTTPS 执行正常的证书校验，不发送路径、查询参数、Cookie 或登录凭据。最长等待 25 秒，可随时取消。
