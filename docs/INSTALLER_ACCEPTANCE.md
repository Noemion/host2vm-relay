# 安装器验收

本版为 v0.6.3。安装程序的实际运行由用户执行。

## 验收内容

| 场景 | 预期结果 |
| --- | --- |
| 运行时缺失 | 提示安装对应架构的 .NET 8 桌面运行时，并保留旧版。 |
| 首次打开 | 显示安装界面。分别记录首次和重复启动耗时；两秒目标待确认。 |
| 确认前取消 | 旧版程序、配置和快捷方式保持不变。 |
| 升级 | 确认安装后显示版本变化、进度和操作记录。旧版处理完成后安装新版本。 |
| 总进度 | 从确认安装后的 0% 开始，检查、卸载、安装和收尾共用一个持续可见的进度条。阶段切换不隐藏、不归零、不倒退；成功完成后才显示 100%。 |
| 文件安装 | 卸载按已移除的旧文件数量推进，安装按实际安装进度推进。等待操作完成时允许停留；记录显示完整文件路径，最终显示安装完成。 |
| 卸载失败 | 停止后续安装，显示原因，允许处理后重试。 |
| 界面布局 | 标题、状态、进度条和记录框层次清晰。长路径可横向滚动，不遮挡按钮。 |
| 配置保留 | 升级后仍可读取原有配置和配置目录。 |

## 已知验证边界

最终安装交互尚待验收。之前的流程测试使用了较早代码和隔离测试安装器，不能证明最终版本全部通过。

Microsoft Defender 曾隔离两份临时测试安装器。告警原因尚未确认；原始记录保存在本地 `artifacts/checks/defender-investigation/`。这些测试程序不属于正式安装包，默认构建也不会生成或运行它们。保持隔离状态，不通过关闭防护或添加排除项完成验收。

安装器代码没有联网检查、解压应用文件或卸载旧版等启动前任务。系统安全检查和磁盘读取仍可能影响首次启动，不能承诺所有环境均在两秒内显示窗口。
