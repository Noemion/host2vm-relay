# 安装器验收

安装程序使用 Inno Setup 的标准现代向导，实际运行由用户执行。

## 验收内容

| 场景 | 预期结果 |
| --- | --- |
| 页面顺序 | 应用介绍 → 安装路径 → 开始菜单名称 → 桌面快捷方式 → 安装确认 → 安装；已有安装也展示这些页面。 |
| 应用介绍 | 中英文内容完整显示在标准欢迎页内，无裁切、横向或纵向滚动条。 |
| 安装确认 | 显示已安装版本、目标版本、运行时检测结果、应用运行状态、路径、开始菜单名称和桌面快捷方式选择。返回修改选项后再次进入，显示最新结果。 |
| 版本判断 | 未安装为首次安装；较低版本为升级；相同版本（含末尾零）为重新安装；较高版本为降级。检查 0.6.9 与 0.6.10 的数值顺序。版本缺失或无法解析时明确提示，不能误报首次安装。 |
| 安装语言 | 首次安装、重新安装和升级均跟随当前用户的 Windows 显示语言，不弹出语言选择框。简体中文显示中文，英文显示英文；未匹配内置语言时回退英文。 |
| 语言变更 | 上次用中文安装后，将 Windows 显示语言改为英文并使其生效，再次安装应显示英文；反向切换也应生效。更改地区格式不应改变安装语言。 |
| 运行时缺失 | 提示安装对应架构的 .NET 8 桌面运行时，并保留旧版。 |
| 首次打开 | 显示安装界面。分别记录首次和重复启动耗时；两秒目标待确认。 |
| 确认前取消 | 旧版程序、配置和快捷方式保持不变。 |
| 应用正在运行 | 主窗口打开或缩到托盘时均能打开安装向导；确认安装后，可在标准页面选择自动关闭应用，随后继续旧版处理与安装。当前转发连接会断开。 |
| 拒绝关闭或关闭失败 | 不移除旧版、不覆盖程序文件；给出明确原因。取消关闭提示也不改变旧版与配置。 |
| 更改安装路径 | 仍能检测并关闭旧目录中的应用，然后移除旧版并安装到新目录。 |
| 升级 | 确认安装后显示版本变化、进度和操作记录。旧版处理完成后安装新版本。 |
| 总进度 | 从确认安装后的 0% 开始，将检查、卸载、安装和收尾计入同一总进度。标准准备页切换到安装页后延续原进度与操作记录，不归零、不倒退；成功完成后才显示 100%。 |
| 文件安装 | 卸载按已移除的旧文件数量推进，安装按实际安装进度推进。等待操作完成时允许停留；记录显示完整文件路径，最终显示安装完成。 |
| 卸载失败 | 停止后续安装，显示原因，处理后可重新运行安装程序。 |
| 界面布局 | 使用标准窗口尺寸、字体、页眉、图片和导航按钮。仅在进度条下方补充操作记录，长路径可横向滚动，不遮挡按钮。 |
| 配置保留 | 升级后仍可读取原有配置和配置目录。 |

## 启动方式验收

- 默认两个选项均关闭。分别修改开机自启动与静默启动，确认界面反馈，无额外确认框。
- 同时启用后重新登录 Windows：应用只显示托盘图标，双击可打开主窗口；不会自动连接虚拟机。
- 关闭静默启动后重新打开应用：正常显示窗口。关闭开机自启动后重新登录：不启动应用。
- 启用自启动后升级并更改安装路径：启动项应指向新目录，静默启动偏好保留。
- 卸载后对应启动项移除；另一份便携程序的启动项不应被删除。

## 已知验证边界

最终安装交互尚待验收。之前的流程测试使用了较早代码和隔离测试安装器，不能证明最终版本全部通过。

Microsoft Defender 曾隔离两份临时测试安装器。告警原因尚未确认；原始记录保存在本地 `artifacts/checks/defender-investigation/`。这些测试程序不属于正式安装包，默认构建也不会生成或运行它们。保持隔离状态，不通过关闭防护或添加排除项完成验收。

安装器代码没有联网检查、解压应用文件或卸载旧版等启动前任务。系统安全检查和磁盘读取仍可能影响首次启动，不能承诺所有环境均在两秒内显示窗口。
